搬运数据

如果这里能看到数据，点「导出为备份 JSON」，然后在你要长期使用的那个地址打开应用， 进入设置 → 导入数据选择该文件（合并或覆盖）即可搬过去。 附件为二进制文件，不含在此 JSON 中，需要重新上传。

找不到数据时

  1. 回想之前是从哪个地址打开的：开发服务器通常是 http://127.0.0.1:5173，预览构建产物是 http://127.0.0.1:4173，双击单文件则是 file://。
  2. 把本页面地址里的域名和端口逐个换成上面这些，依次打开看「本地数据」是否非空。
  3. 注意 localhost 与 127.0.0.1 在浏览器里是两个不同的源，数据不互通。
  4. 找到有数据的地址后，导出 JSON，再到固定地址导入。
  5. 若所有地址都是空的，说明浏览器站点数据已被清除（清理软件、隐私模式、手动清理过），只能从备份文件恢复。
